# 歩兵と戦車（2026-11-08）

ロシア兵が押し寄せるイメージに合わせ、歩兵をオリーブ色の軍服、ヘルメット、防弾ベスト、ライフルの姿にしました。プリミティブで作る簡略表現です。前進に合わせた手足の動きは維持しています。

歩兵に混ざり、履帯・車体・砲塔・砲身を持つ戦車が出現します。

| Enemy Pool / EnemySpawner の設定 | 初期値 |
|---|---|
| Tanks Enabled | ON |
| First Tank Seconds | 12秒 |
| Tank Interval | 14秒 |
| Tank Capacity | 3体分を事前生成 |
| Tank Health | 18（Damageが1なら18発命中で撃破） |
| Tank Speed | 1.2 / 秒 |
| Tank Hit Radius | 1.05 |
| Tank Score | 100点 |

戦車の上にはARMORと残りHPのバーを表示します。弾は歩兵・戦車のうち最も手前の1体に当たり、貫通しません。戦車の防衛ライン突破は歩兵同様、ライフを1減らし、自軍人数を半分にします（端数切り上げ、最低1人）。戦車からの砲撃はありません。

通常の60秒ラウンドでは、おおむね12・26・40・54秒に出現します。ラウンド終了、敵全体の上限、戦車プールの空き状況によって出現しない場合があります。敵全体の同時出現数はCapacity（最大100体）以内です。歩兵用Capacity体と戦車用Tank Capacity体を開始時に準備し、戦闘中の生成は行いません。追加マテリアルは全個体で4つを共有し、終了時に破棄します。

再出撃では全敵を消去し、戦車の初回出現タイミングもリセットします。戦車を再利用するとHPは最大まで戻ります。

## 反映と検証

既存のUnityプロジェクト `D:\UnityProjects\LastLine\LastLine` に反映済みです。シーン再生成は不要です。設定を変える場合はPlayを停止してEnemy PoolのInspectorで変更し、保存してください。HP・速度・半径・得点・プール数は次のPlay開始時に適用されます。

- Unity 6000.6.8f1参照のRuntime / Editor独立コンパイルと3入力条件の構文検査に成功。
- Unity EditorのRun Edit Mode Checks / Run Play Mode Checksに成功。18発での撃破、後ろの敵への非貫通、得点の二重計上防止、戦車の再利用とHP復元、突破の一度だけの計上、歩兵と戦車の合計上限、再出撃、初回出現タイミングを確認。
- 純C#の49テストも成功。検証中に既存の40秒ウェーブ境界の丸め誤差を発見し、ちょうど40秒で最終ウェーブへ進むよう修正。
- 通常Playで軍装した歩兵、戦車の出現、ARMOR 18/18の表示を目視確認。確認後はPlayを停止し、Editorのレイアウトを戻しました。シーンは保存していません。
- Windows再ビルド、Android実機、100体時の描画性能、難易度の調整は未実施。

バッチ検証の入口も `LastLine.Editor.PrototypeChecks.RunBatchChecks` に追加しています。同じプロジェクトをUnity Editorで開いている間は別プロセスでの検証は起動できないため、今回のPlay Mode検証は開いていたEditorのメニューから実行しました。

## 接近と命中の確認
戦車の頭上に、防衛線までの距離と現在の移動速度から求めた到達秒数（LINE）を表示します。残り5秒で赤に変わります。戦車の正面に移動して撃ち、撃破前の命中時に装甲表示が短く白く光り、車体が揺れることを確認します。ルール62項目、3入力構成の構文検査、Unity参照コンパイルは成功。端末上の視認性は未検証です。

## 履帯の土煙（0.1.6）
戦車が進むと左右の履帯の後端から交互に土煙が立ち、地面近くに残ってから縮みます。走行距離に応じた演出で、各車の4個のメッシュと全車共通のマテリアルを再利用します。再出現時には前の煙を消します。実機では消音で戦車の進行方向を読み取れるか、土煙が歩兵や支援標的を隠さないかを確認してください。

## 歩兵の構え（0.1.8用ソース）
敵歩兵・操作兵・増援の頭部を縦長に整え、右肩に寄せた銃の前部を左手、手元を右手で支える姿勢にしました。Unity参照コンパイルと3入力構成の構文検査は成功。Unityのライセンス認証でEditor起動が停止したため、実際の縦画面での視認性・最大編成の描画負荷・APK生成は未確認です。
