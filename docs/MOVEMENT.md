# 射手が左右にステップする操作へ変更

固定砲台の角度を変える操作から、**マシンガンを持つ射手自身が左右へ移動し、正面へ自動射撃する操作**へ変更しました。

- マウスの画面内の左右位置が移動先になります。クリックは不要です。
- タッチ中の指の左右位置も同じ移動先として扱います。
- 射手は指定速度で移動し、画面端からはみ出しません。
- 射撃方向は戦場の奥（ワールド+Z）に固定し、移動先から毎秒10発発射します。
- 発射済みの弾は射手の横移動に引っ張られません。
- 敵は現在の射手のX座標に向かって前進し、防衛線を越えるとライフが減ります。
- RETRYで射手の開始位置と歩行姿勢をリセットします。

## 見た目と既存シーン

射手は頭・胴体・腕・脚・マシンガンのプリミティブで表現します。横移動に合わせて脚を動かし、体を少し上下させます。外部キャラクターやアニメーション素材は使用しません。

**既存シーンの再生成は不要**です。旧シーンではPlay開始時にShooterControllerを追加し、砲台のBase/Body/Barrelを非表示にして人型を生成します。シーンの敵・武器・ライフなどの調整値と参照は維持します。Play中は旧Turretオブジェクトの名前もShooterになります。Play停止後に元の名前へ戻るのは通常の動作です。

新しく `Create Minimal Scene` で生成したシーンは、最初からShooterと人型を含みます。

## Inspectorの調整

Play中はGameRoot配下の **Shooter > ShooterController** を選んで調整できます。停止すると値は戻ります。

| 項目 | 初期値 | 意味 |
|---|---|---|
| Move Half Width | 5.5 | 中央から左右それぞれの移動範囲（ワールド座標） |
| Move Speed | 16 | 毎秒の移動距離。小さくするとゆっくり追従する |

旧シーンで調整を保存したい場合は、Playを停止し、MachineGunが付いている **Turret** を選んで **Add Component > Shooter Controller** を追加してください。Move Half WidthとMove Speedを設定し、Ctrl+Sでシーンを保存します。GameControllerのShooter欄が空でも開始時に同じオブジェクト上のコンポーネントを見つけます。

## 確認すること

1. Unityに戻り、コンパイルが終わってからPlayします。
2. マウスを左右に動かし、人型の射手が横へ移動することを確認します。
3. 左右端でも射撃が画面奥に向いていること、移動前に撃った弾が途中で横へ曲がらないことを確認します。
4. 敵の列の正面へ移動して倒します。
5. RETRYで射手の位置が最初に戻ることを確認します。

既存のLastLine.exeは古い操作のままです。Unityで今回の操作を確認できてから、`Build Windows (Current Scene)` で再ビルドしてください。

## 検証範囲

純C#の49テストで、左右位置の対応、移動速度、左右端、目的地を通り過ぎないこと、方向反転、停止、フレームレートによる差を含めて確認しています。Unity 6000.6.8f1の参照でRuntime/Editorの独立コンパイルも確認しています。

Play Modeチェックには射手の自動初期化、人型の生成、正面方向、再試行での位置リセットを追加しました。この追加版の実際の操作感・人型表示・Android実機・Windows再ビルドは未確認です。
