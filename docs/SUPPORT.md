# 撃って獲得する支援ターゲット（2026-11-08）

敵を撃つだけでなく、狙うレーンを選んで支援ターゲットを撃つゲーム性を追加しました。ターゲットには効果名と残りHPが表示されます。

| ターゲット | 色 | 獲得効果 |
|---|---|---|
| SQUAD +1 | 緑 | 味方兵士を1人追加。プレイヤーと合わせて最大5人。左右に追従し、各自が正面へ射撃 |
| WEAPON UP | 黄 | 武器レベルを1上昇。最大Lv.4。全員の威力と連射速度を強化 |
| DRONE STRIKE | 橙 | ドローン爆撃を要請。戦車を優先し、その次に防衛線へ近い歩兵を狙う |

初期設定は開始3秒後に増員ターゲットが出現し、以後5秒間隔を目安に、増員→武器→ドローンの順を繰り返します。同時に出るターゲットは1つです。前のターゲットが残っている場合は、獲得・消滅後に次が出現します。

ターゲットのHPは3です。初期武器なら3発命中で獲得し、強化後は武器のダメージに応じて必要弾数が減ります。

ターゲットは敵と同じSpawn Zから現れ、歩兵PrefabのMove SpeedにTarget Speed Multiplier（初期値1）を掛けた速度で手前へ直進します。左右は原則、自軍の現在位置と反対側のレーンです。中央にいる場合は左右をランダムで選びます。出現レーンが狭い設定では、移動できる範囲内へ収めます。

敵を倒す射線を維持するか、反対側へ移動して支援を狙うかを選びます。ターゲットは防衛線へ到達すると消え、見逃してもライフは減りません。従来の7秒の時間制限は撤廃しました。弾は敵・戦車・ターゲットのうち最も手前の1つに当たり、貫通しません。

## 味方と武器

増員した兵士は左右の横移動に追従します。初期設定では、1人当たりの射撃はLv.1で2発/秒・ダメージ1、Lv.2で2.5発/秒・ダメージ2、Lv.3で3発/秒・ダメージ3、Lv.4で3.5発/秒・ダメージ4です。InspectorのShots Per Second / Damageを変えた場合は、その基礎値に強化が加算されます。

増員・武器レベルの上限に達した後は、その種類のターゲットを獲得してもさらに増えません。画面下部に現在の人数・武器レベル・待機ドローン要請数を表示し、獲得時には通知を出します。

敵の歩兵または戦車が防衛線を突破すると、プレイヤーを含む自軍人数が半分になります。端数は切り上げ、5人→3人→2人→1人と減ります。操作する兵士は最低1人残り、従来通り突破1回につきライフも1減ります。同じ敵による二重の減少はありません。隊列から外れた味方は次の斉射から射撃せず、増員ターゲットで再び人数を増やせます。武器レベルやドローン要請は失いません。すでに発射された弾は飛び続けます。突破時は赤い警告と人数の変化を2秒間表示します。

## ドローン爆撃

獲得すると4枚のローターを持つドローンが約1秒で飛来し、敵の上空から爆弾を約0.6秒かけて投下します。着弾で火球・衝撃波・立ち上る煙を出し、ドローンは約0.7秒で離脱します。初期ダメージは24、爆風半径は3.2です。敵の当たり判定半径も範囲判定に含めます。18HPの戦車を1回の爆撃で撃破でき、近くの歩兵も巻き込めます。

ドローンは進入中に敵を追跡し、投下開始時点の敵位置を爆撃します。着弾時の範囲内にいる敵がダメージを受けます。画面全体への攻撃ではありません。敵がいないときは最大3回まで要請を待機し、敵が現れると順次出撃します。撃破時は通常の得点と撃破演出が発生します。飛来時や投下前にはダメージを与えません。

## 既存シーンと設定

既存シーンではGameControllerが起動時にSupportTargetsを自動追加するため、シーンの再生成は不要です。`D:\UnityProjects\LastLine\LastLine` へ反映済みです。

新たに生成するシーンにはSupportTargetsを保存します。既存シーンで支援の値を永続的に調整したい場合は、Play停止中にGameRootへSupportTargetsを追加して保存してください。First Target Seconds / Target Interval / Target Health / Target Speed Multiplier / Drone Damage / Drone Radiusで調整します。以前のMissile Damage / Missile Radiusの保存値は引き継ぎます。

味方4人分・3種類のターゲット・ドローン・爆弾・爆風と煙は開始時に事前生成します。弾のプールも最大編成と武器強化を考慮して拡張します（上限256発）。極端なInspector設定ではプール不足により射撃が間引かれる場合があります。戦闘中に新しいオブジェクトは生成しません。

ターゲット、飛行中と待機中のドローン、爆弾、爆発は毎ステージ・再試行でリセットします。クリア時の味方人数と武器レベルは次のステージへ引き継ぎ、敗北時の再試行ではそのステージに入った時点の装備へ戻します。新しい作戦を始めると味方・武器強化も初期化します。[ステージ進行の仕様](CAMPAIGN.md) を参照してください。ラウンド終了後の獲得や攻撃は停止します。

## 検証

- 全14ファイルの3入力条件での構文検査とUnity 6000.6.8f1参照のRuntime/Editor独立コンパイルが成功。
- 実プロジェクトのUnity EditorでEdit Mode / Play Modeチェックが成功。
- 敵とターゲットの近接順・非貫通、複数回命中、一度だけの獲得、人数上限、実際の2発/5発の斉射、威力と連射速度の強化、武器レベル上限を確認。
- 敵がいない場合のドローン待機、戦車優先、投下前の無ダメージ、投下と爆発の表示、着弾後の範囲攻撃、遠い敵への無影響、撃破の一度だけの加点、離脱と演出消去を確認。
- 敵と同じ奥行き・反対側レーンでの出現、直進、旧7秒制限の撤廃、防衛線での消滅、3種類の出現順、ラウンド終了後の獲得停止、再出撃での初期化を確認。
- 難易度、継続プレイの操作感、Windows再ビルド、Android実機、最大編成の描画性能は未確認。

演出だけを見る場合は、Play停止中に **Last Line > Preview Drone Strike** を選びます。低速のプレビュー用Playへ入り、戦車と近くの歩兵を爆撃します。Playを停止すると速度とシーン設定は元に戻ります。プレビュー中のシーンは保存しないでください。
