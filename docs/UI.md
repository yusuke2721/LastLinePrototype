# HUDの刷新（2026-11-08）

このページは最初のHUD刷新の記録です。現在のタイトル・ステージ進行・描画と反映方法は [CAMPAIGN.md](CAMPAIGN.md) を参照してください。

ダークネイビーとシアンの戦術モニター風HUDに変更しました。UIパッケージ・画像・フォントの追加は不要です。既存のGameHudコンポーネントとカメラ参照をそのまま使います。

- 上部：タイトル、5桁以上のスコア、残り時間、ラウンド全体の進行バー。
- 下部：防衛ラインの耐久ゲージ、残りライフ / 初期ライフ、横移動の操作案内。
- 残り10秒以下で時間を黄色、ライフ30％以下で耐久表示を赤に変更。色と文字で状態を伝えます。
- 終了時：戦場を暗くし、勝敗、最終スコア、生存時間、大きな「DEPLOY AGAIN」ボタンを表示。ボタンは従来のRETRYと同じラウンド初期化を呼び出します。
- 540×960を基準に、カメラの表示範囲とScreen.safeAreaの交差領域へ等比で収めます。横長ウィンドウの余白にはHUDを出しません。

## 初戦の操作案内（0.1.5）
1面の防衛ゲージ下に操作案内を表示します。支援がない間は横移動と自動射撃の説明、標的が現れたら銃口から見た左右の移動方向、射線が合えばその位置を維持する案内に切り替わります。支援を一度獲得すると残り時間を守る目標に切り替わります。1面を再試行すると案内も最初に戻ります。

## コンボとオーバードライブ（2026-11-10）

撃破をつなぐほど得点と火力が上がる仕組みです。追加操作は不要で、歩兵・戦車・ドローンによる撃破が対象です。支援ターゲットの獲得や、敵への着弾だけではコンボは増えません。

| 状態 | 効果 |
|---|---|
| 1〜3連続撃破 | 基本得点。最後の撃破から4秒未満で次を倒すと継続 |
| 4〜7連続撃破 | 4体目から得点2倍 |
| 8連続撃破 | 8体目からオーバードライブ：6秒間、得点3倍・プレイヤーと全味方の連射速度2倍 |
| 通常時に4秒経過 | コンボと得点倍率をリセット |
| 防衛線突破 | コンボと発動中のオーバードライブを即解除。武器レベルは維持 |

発動中の撃破も最高コンボに数えますが、6秒の効果時間は延長しません。通常の4秒制限は発動中に適用せず、効果終了時にコンボを0へ戻して再び蓄積できます。最高コンボは突破や時間切れでも残り、結果画面に表示します。再試行・次ステージ・タイトルへ戻る操作で現在値と最高値の両方を初期化します。コンボはセーブへ持ち越しません。

上部ヘッダーの下に発動までのゲージと得点倍率を表示し、細いゲージで次の撃破までの猶予時間を示します。発動中は黄色へ変わり、連射2倍と残り秒数、残り効果時間のゲージを表示します。弾のプールは最大武器・最大編成での2倍連射を考慮して確保します（既存の256発上限は維持）。

反映するファイルはRuntimeの `CombatRules.cs`、`MachineGun.cs`、`GameHud.cs` と、Editorの `PrototypeChecks.cs` です。既存の `.meta` を維持してUnity側へコピーしてください。シーン再生成は不要です。Android APKは0.1.10から対応します。

確認手順：4秒未満の間隔で8体倒してゲージと発動を確認し、6秒後に通常連射へ戻ることを確かめます。発動中に突破されると即解除され、リザルトに最高コンボが残り、再試行では0になります。自動検証は `tools/Verify-Rules.ps1` と **Last Line > Run Play Mode Checks** に追加しています。見た目の読みやすさ・実機性能・難易度の調整は別途プレイで確認します。
