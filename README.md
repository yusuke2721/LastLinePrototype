# LAST LINE

Unity 6 / C#で作る、9:16の3D防衛シューティングの最小プロトタイプです。プリミティブによるオリジナルの表現とUnity標準機能を使い、有料アセット・外部ゲームのコードは使用しません。

## 現在の状態

**Unity 6のプロジェクトへ取り込むソースリポジトリです。まだHubでそのまま開ける完全なUnityプロジェクトではありません。** 実際の動作確認プロジェクトはUnity 6000.6.8f1です。このリポジトリにはまだPackagesやProjectSettingsを取り込んでいません。

正面への毎秒2発の自動射撃、マウス/タッチによる射手の横移動、敵のHP・直進移動・撃破、防衛ラインとライフ、60秒クリア、得点、再試行、敵/弾プール、シーン生成メニューを実装しています。敵の出現間隔は0〜20秒が0.65秒、20〜40秒が0.3秒、40〜60秒が0.1秒に変化します。マズルフラッシュとプール式の撃破演出も追加しています。

タイトル画面、クリア後に難易度が上がるステージ進行、味方・武器の引き継ぎを追加しました。土・土嚢・装備・装甲の質感と陰影も整えています。[ステージ進行と描画の仕様](docs/CAMPAIGN.md) を参照してください。

ステージの配色は1: オリーブ、2: 深紅、3: 砂色、4: ネイビー、5: 灰色、6: 紫系で、7以降は循環します。敵の軍装・戦車・地面・UIに反映しています。

純C#の62テスト、全16ファイルの3入力条件の構文検査、Unity 6000.6.8f1参照のRuntime/Editor独立コンパイル、実EditorのEdit/Play Modeチェックが成功しています。タイトル→出撃→クリア→ステージ2の操作も確認済みです。現在のWindows再ビルド・Android実機・最大編成の性能測定・全ステージの難易度調整は未実施です。

知人配布用のAndroid APK（0.1.2、約30MB）を `Builds/Android/LastLine-0.1.8-arm64.apk` に生成しました。Android 8.0以降のARM64端末向けで、テスト用署名とパッケージ整合性を確認済みです。APKはGit管理対象外です。[配布と再ビルド](docs/ANDROID.md) を参照してください。

UIをダークネイビーとシアンのHUDへ刷新しました。残り時間・進行バー・耐久ゲージ・勝敗別の結果画面を表示します。既存シーンの再生成は不要です。[UIの変更と反映手順](docs/UI.md) を参照してください。

敵はオリーブ色の軍服・ヘルメット・ベスト・ライフルを持つ歩兵です。前進に合わせて手足が動き、時折18HPの戦車も出現します。既存シーンの再生成は不要です。[歩兵と戦車の仕様・調整方法](docs/TANKS.md) を参照してください。

撃って獲得する支援ターゲットも追加しました。敵と同じ奥から反対側のレーンを進むターゲットを狙い、味方の増員（最大5人編成）、全員の武器強化（最大Lv.4）、戦車を優先するドローン爆撃を利用できます。[支援ターゲットの仕様](docs/SUPPORT.md) を参照してください。

敵に防衛線を突破されると、自軍人数が半分になります。端数は切り上げ、操作する兵士は最低1人残ります。ライフ減少に加えて射撃人数も減るため、敵の突破を防ぐ重要性が増します。

## ストア公開に向けた改良計画（提案）

Android先行を想定し、次の順に進めます。各段階で実機のプレイ結果を見て次の範囲を決めます。

| 段階 | 作る・確かめるもの | 次へ進む目安 |
|---|---|---|
| 1. 実機の基準を作る | 0.1.1を新規インストール・旧版から更新し、タイトル、出撃、勝敗、再試行を確認。終盤の密集時と最大編成のフレーム時間を記録する。 | 対象端末で一連の操作ができ、指で隠れる場所や処理落ちする場面を特定できる。 |
| 2. 最初の60秒を磨く | 歩兵の足音、戦車の履帯音と土煙、装甲への着弾音を試す。支援へ移る隙と防衛線の危険を画面だけでも読めるようにする。 | 初見の人が横移動を覚え、支援を取りに行った理由と突破された理由を説明できる。 |
| 3. 3面の短い作戦を作る | 1面は歩兵と増援、2面は戦車とドローン、3面は左右からの時間差攻撃で守る順番を選ばせる。突破後に編成が減っても立て直せるか測る。 | 各面で異なる判断が生まれ、失敗した人が次に変える行動を一つ挙げられる。 |
| 4. 公開候補を仕上げる | 面クリア時の進行保存、復帰、音量設定、短い操作案内を整える。署名済みの公開候補をテスト配布し、ストア説明・画像を実際のプレイと照合する。 | 更新後も進行が復元され、対象端末で初回起動から作戦終了まで通せる。提出時点のストア要件を確認する。 |

## フォルダー構成

```text
Assets/LastLine/     ゲーム本体とEditor拡張（.metaを含む）
docs/SETUP.md       Unityへの導入・操作・Inspector調整・ビルド手順
docs/VALIDATION.md  実施済みと未確認の検証範囲
docs/validation/   実行結果ログ
docs/GIT.md        初回コミット・GitHub接続・Unityプロジェクト化の手順
tools/             Unityなしで実行できる検証スクリプト
.gitignore         Unityのキャッシュ・ビルド・個人設定の除外
.gitattributes     テキストの改行とバイナリの扱い
```

まず [導入手順](docs/SETUP.md) に従い、Unity 6の3DプロジェクトへAssetsを取り込み、**Last Line > Create Minimal Scene** を実行してください。`.meta`も一緒にコピーします。

## 検証（PowerShell 7）

リポジトリ直下で実行します。

```powershell
pwsh -NoProfile -File .\tools\Verify-Rules.ps1
pwsh -NoProfile -File .\tools\Verify-Syntax.ps1
# Unityを使った独立コンパイル手順はdocs/EFFECTS.mdを参照
```

Unity上では **Last Line > Run Edit Mode Checks / Run Play Mode Checks** を利用できます。詳細は [検証記録](docs/VALIDATION.md) に記載しています。
